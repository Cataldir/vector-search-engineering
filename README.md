# Vector Search Engineering

Public destination for the learner code companion to Vector Search Engineering.

## Current status

The practical companion has not been authored and qualified for release. This repository currently contains this entry note only. It does not yet provide an installable or tested retrieval service.

The intended companion covers index selection, versioned ingestion, hybrid retrieval, reranking, tenant isolation, and reproducible recall and latency measurement. Guided exercises and reference solutions will accompany the code. Dataset and model redistribution will require their own provenance and terms.

## Learner route

Use the published release instructions once the code is available: clone the repository, create its isolated environment, acquire the declared inputs, run the retrieval and isolation checks, complete a starter exercise, compare the reference solution, and measure an extension. No benchmark result or production performance is claimed by this entry note.

## Content and reuse

The companion is intended for reusable code, practical instructions, and exercises. Course narration, slides, books, and videos are outside this repository. The code release will include its license, dependency attribution, and data provenance. No code license or third-party redistribution rights are established by this note.
